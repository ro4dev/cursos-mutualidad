# acentos-lista.txt — palabras cuya tilde NO se puede deducir por sufijo.
#
# Formato:  forma-sin-tilde=forma-con-tilde
# El grupo -cion/-sion NO aparece aqui: lo cubre una regla en acentos.mjs.
# Solo lo inequivoco. Si una palabra puede ir con o sin tilde segun el
# contexto, queda fuera (aun, solo, esta). Si duda, no la agregues.
#
# ANTES DE AGREGAR UN PLURAL, LEER ESTO. Es el error que mas se repite:
#
#   esdrujula  -> el plural sigue esdrujula y MANTIENE la tilde
#                xisito / exitos, metodo / metodos, telefono / telefonos
#   llana      -> el plural sigue llana y NO lleva tilde
#                util / utiles, facil / faciles, debiles, generos
#   aguda      -> el plural pasa a ser llana y PIERDE la tilde
#                guia / guias, via / vias, interes / intereses
#
# O sea: una entrada de plural solo es valida si el singular es esdrujula.
# "guias" y "vias" estuvieron en esta lista y no debian: son el plural de una
# aguda, asi que van sin tilde. "generos" si la lleva, porque "genero" es
# esdrujula.
#
# La enie es un caso aparte y siempre cambia: ano/anos, dana/danas, senal/senales.
# Esas entradas son correctas porque lo que se agrega es la enie, no una tilde.

# --- "video" NO va aqui ---
# La RAE acepta "video" y "vídeo", y la forma con tilde es la preferida en
# España. En Chile la forma establecida es "video" sin tilde, y el repositorio
# es es-CL. Meterla en CON_TILDE obligaba a escribir "vídeo" en 970 lugares
# distintos. Va en SIN_TILDE_PERMITIDO, que es donde el detector deja de
# exigirla.
#
# --- agudas de hiato: el acento cae en la vocal cerrada y siempre lleva tilde ---
# El guard de acentos es tan bueno como esta lista: solo ve lo que hay aqui.
# "ocurrio" se escapo de un titulo en pantalla y llego renderizado, porque
# ninguna de las dos reglas de sufijo (-cion/-sion) lo cubre y nadie lo
# escribio en la lista. Se encontro auditando a mano el vocabulario visible de
# los 88 frames, no confiando en el guard: por eso esta seccion.
#
